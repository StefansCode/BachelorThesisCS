Das Ziel der Arbeit ist die Entwicklung einer dsv-Bibliothek für 
Mikrocontroller. Insbesondere für den ESP32-S3, da die Entwicklung der
Bibliothek auf diesem stattfindet. Der Vorteil und Fokus dieser Bibliothek
liegt auf der Erweiterbarkeit und Nutzerfreundlichkeit. Im bezug auf
Nutzerfreundlichkeit ist Java Streams \cite{java2026stream} ein 
sehr gutes Vorbild. Java Streams setzt als fluent API die Mentalität 
\glqq Signal geht rein, Signal geht raus\grqq  (oder im fall von Java Streams
Collection) perfekt um. Als zentrale Komponente der dsv-Bibliothek soll es 
also eine Klasse geben, welche ein Signal von einem Eingang nimmt, es mit 
verschiedenen Funktionen bearbeitet und danach an einen Ausgang abgibt.
Die Erweiterbarkeit soll dabei durch Signalfunktionen wie applyFunction,
welche selbst definierte Funktionen ausführen, gegeben sein. Außerdem soll die
Signalklasse nicht zu komplex werden und somit leicht erweiterbar sein.
