\section{Einleitung}

Digitale Signalverarbeitung (DSV) ermöglicht die softwarebasierte Verarbeitung
und Erzeugung von Signalen und findet unter anderem in der Audioverarbeitung 
Anwendung. Durch die zunehmende Leistungsfähigkeit von Mikrocontrollern ist
es möglich, solche Signalverarbeitungsverfahren auch auf eingebetteten Systemen 
umzusetzen. 

Ziel dieser Arbeit ist die Entwicklung einer einfach nutzbaren und erweiterbaren
DSV-Bibliothek für Mikrocontroller. In Bezug auf die
Nutzerfreundlichkeit sind Java Streams \cite{java2026stream} ein
sehr gutes Vorbild. Java Streams setzen als Fluent API \cite{fluentAPI} die Mentalität
\glqq Signal geht rein, Signal geht raus\grqq\ (bei Java Streams eine
Collection) und die sequentielle Abarbeitung von Streams sehr gut um.
Da C++ auch objektorientierte Programmierung unterstützt, ist es möglich, eine
ähnliche Fluent API in C++ zu implementieren. 
In Abbildung \ref{Vergleich_Streams_Signal} wird diese sequentielle
Abarbeitung dargestellt und gezeigt, wie eine Anwendung der DSV-Bibliothek
aussehen könnte.

Neben der DSV-Bibliothek soll es außerdem eine Audiobibliothek geben, welche
auf Audiosignale spezialisiert ist. Der größte Unterschied
zwischen diesen liegt darin, dass die Audio-Bibliothek das Signal selber erzeugt
und der DSV-Bibliothek ein Signal übergeben wird.

Wegen der Popularität und des günstigen Preis-Leistungs-Verhältnisses des ESP32-S3-
Mikrocontrollers wird die Signalbibliothek auf diesem entwickelt und
soll neben der eigentlichen 
Signalverarbeitung auch die Anbindung an die benötigte Hardware ermöglichen. Hierzu 
wird eine Trennung zwischen der Signalverarbeitung und hardwarespezifischen Komponenten 
sowie der ESP-IDF
angestrebt. Dadurch soll die Bibliothek plattformunabhängig bleiben. 

Als praktische Anwendung der Bibliothek wird ein digitaler Synthesizer entwickelt.
Der Synthesizer dient dabei sowohl als Anwendung der 
Bibliothek als auch zur praktischen Erprobung ihrer Funktionen.
Dafür werden die nötige Hardware aufgebaut und die zugehörige Software implementiert.

\subsection{Verwante Arbeiten}

Die ESP-DSP-Bibliothek \cite{ESPDSV} ist eine DSV-Bibliothek, welche von 
Espressif entwickelt wurde. Sie ist auf die Nutzung der Hardware des ESP32 
optimiert und erwartet Signale in der Form eines Arrays. Der Vorteil der 
zu entwickelnden DSV-Bibliothek ist, dass ein Signal als eine Klasse Fluent API
implementiert wird, was zu leserlicherem Code führt.

Die Mozzi-Bibliothek \cite{Mozzi} ist eine Bibliothek für Tonausgabe und für 
Audiosynthese auf Mikrocontroller. Allerdings wird die Funktionalität der Bibliothek hinter 
Funktionen wie \lstinline|startMozzi| und \lstinline|audioHook| versteckt
\cite{MozziSimpleSketch}. Die zu entwickelnde Audiobibliothek werden 
die Funktionen der Bibliothek sequentiell aufrufen und die Funktionsweise
der Bibliothek ist dadurch für den Nutzer besser nachvollziehbar.
