\section{Digitale Audio}


Die Soundklasse ist eine Erweiterung bzw. eine Anwendung der Signalklasse. 
Diese Erweiterung wird umgesetzt, indem die Soundklasse ein Signal als 
Membervariable besitzt.

\subsection{Auflösung und Abtastrate}

I2S verwendet wie viele ander digitale Audio Systeme
Pulse-Code-Modulation (PCM) Daten. Das ist ein unkomprimiertes Audio format mit
meistens 16, 24 oder 32 Bit unsigned Integern. In dem config Header ist ein 
Datentyp mit dem Namen sample definiert, welcher genau so ein unsigned Int ist.
Hier kann man die Auflösung global einstellen.
