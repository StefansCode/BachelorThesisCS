\section{Die Theorie und Implementation}

In diesem Kapitel wird die Theorie der Signale und Systeme erklärt, wie sie 
in Grüningens Buch Digitale Signalverarbeitung \cite{grueningen2008dsv}
beschrieben wird. Außerdem wird eine mögliche Implementierung vorgestellt.

\subsection{Zeitdiskrete Signale}

Zeitdiskrete Signale werden dargestellt durch Folgen.
\begin{center}
    $\{x[n]\}_{n \in \mathbb{Z} } = \{ ...,x[-2],x[-1],x[0],x[1],x[2],... \}$
\end{center}

In der Praxis können nur endlich viele Werte eines Signals betrachtet werden.
Dies notiert man wie folgt.
\begin{center}
    $\{x[n]\}_{n = 0 }^{N} = \{ x[0],x[1],...,x[N-1] \}$
\end{center}
