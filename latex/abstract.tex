In dieser Arbeit soll eine Bibliothek für die Verarbeitung von
digitalen Signalen entwickelt werden. Diese soll als Fluent API implementiert
werden, um die Nutzung der Bibliothek möglichst einfach zu gestalten.

Außerdem soll eine Erweiterung der Bibliothek für die Verarbeitung und
Generierung von Audiosignalen implementiert werden. 

Mit einem ESP32-S3-Mikrocontroller und weiteren Hardwarekomponenten soll die
Erweiterung genutzt werden, um einen digitalen Synthesizer zu bauen.
Dieser wurde erfolgreich gebaut, und es ist möglich, verschiedene Parameter
der Töne zu verändern. 

Die Signalbibliothek funktioniert im aktuellen Stand. Für die weitere
Entwicklung neuer Funktionen ist jedoch eine Überarbeitung erforderlich.
