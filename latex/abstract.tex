In die dieser Arbeit soll eine Bibliothek für die Verarbeitung von 
digitalen Signalen geschrieben werden. Diese soll als Fluent API implementiert 
werden, um die Nutzung der Bibliothek möglichst einfach zu gestalten. 

Außerdem soll eine Erweiterung der Bibliothek für die Verarbeitung und
Generierung von Audiosignalen implementiert werden. 

Mit einem ESP32-S3 Microcontroller und weiteren Hardwarekomopnenten soll die 
Erweiterung genutzt werden um einen digitalen Synthesizer zu bauen.
Dieser wurde erfolgreich gebaut und es ist möglich verschiedene Parameter
der Töne zu verändern. 

Die Signal Bibliothek funktioniert in dem aktuellen Stand, jedoch ist
für die weitere Entwicklung neuer Funktionen eine Überarbeitung Dieser
nötig.
